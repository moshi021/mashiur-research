# Md. Mashiur Rahman — Research Portfolio

A lightweight, responsive three-page academic research portfolio built with vanilla HTML/CSS/JS.

## Pages
- `index.html` — Home
- `research.html` — Research Interests
- `publications.html` — Publications

## Run locally
Open `index.html` in a browser, or serve the folder with:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes
The visual language is inspired by the clarity and research-first structure common to leading computational materials science group sites, including the supplied Asta, Kang, and Ritchie examples, but the layout and copy are original. Publication visuals were derived from the supplied manuscripts.
